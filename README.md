一款面向餐饮行业的全流程在线点餐解决方案，旨在打通用户点餐、商家接单、订单管理、数据统计等核心环节，助力餐饮商家实现数字化转型，提升运营效率与用户消费体验。项目采用前后端分离架构设计，具备良好的可扩展性、可维护性与跨端适配能力。
核心功能

- 用户端：菜品浏览、分类筛选、购物车管理、在线下单、订单支付、订单查询、评价反馈等；

- 商家端：菜品管理（新增/编辑/上下架）、订单管理（接单/拒单/完成/取消）、餐桌管理、营业数据统计（销量/营收/客流）等；

- 系统核心：用户权限控制、订单状态流转、数据持久化存储、异常处理与日志记录等。

🔧 技术栈选型

采用主流且成熟的技术组合，兼顾开发效率与系统性能：

- 前端技术：Vue3（Composition API 语法，高效组件化开发），具备更好的响应式性能与TypeScript支持，适配PC端、移动端等多终端场景；

- 后端技术：SpringBoot（快速构建微服务架构基础）、Java（稳定可靠的后端开发语言）、MyBatis（轻量级ORM框架，简化数据库操作）；

- 数据库：MySQL（开源高效的关系型数据库，适配中小规模餐饮企业的数据存储需求，支持复杂查询与事务处理）；

- 辅助技术：Node.js（可用于构建后端服务或前端工程化工具链，提升开发流程自动化水平）。

开发工具

- 前端开发：VS Code（轻量强大的代码编辑器，搭配Vue插件可实现语法高亮、代码补全、调试等功能）；

- 后端开发：IntelliJ IDEA（专业的Java开发IDE，提供完善的SpringBoot集成、代码重构、版本控制等能力）；

- 数据库管理：DataGrip（高效的数据库工具，支持MySQL等多种数据库连接，具备可视化查询、表结构设计、数据导入导出等功能）。

适用场景

适用于快餐店、奶茶店、正餐餐厅、校园食堂、企业食堂等各类餐饮场景，可根据实际需求进行二次开发与功能定制，支持单店部署或多店连锁管理模式。

📋 项目优势

- 前后端分离：降低前后端耦合度，便于团队分工协作与后续功能迭代；

- 技术成熟稳定：选用主流技术栈，文档丰富、社区活跃，问题解决成本低；

- 功能贴合需求：覆盖餐饮点餐全流程核心场景，无需大量额外开发即可快速上线；

- 易扩展易维护：代码结构清晰，遵循开发规范，支持后续功能扩展（如外卖配送、会员体系等）。

快速开始

1. 克隆本项目至本地；

2. 前端：进入前端目录，执行 npm install 安装依赖，npm run dev 启动开发服务；

3. 后端：导入IDEA，配置MySQL数据库连接信息，启动SpringBoot应用；

4. 访问对应端口即可体验系统。
